# Xiazhouqi Bilibili Cover Skill v1.1

下周七 B站科技教程封面规范。

## 文件

- `SKILL.md`：完整设计规则
- `REFERENCE_CANONICAL_16x9.jpg`：当前 B站视觉母版（已更新为 Gemini 这一版），负责锁定颜色、光线、边框、材质、层次与高级感
- `REFERENCE_PREVIEW_4x3.png`：中央 4:3 裁切预览，只用于理解 B站首页裁切，不作为风格母版

## 当前定版重点

这一版以你最终确认的 Gemini 横版封面为准，重点锁定：

- 暖奶杏、低饱和、自然柔光
- 真实产品摄影感与桌面空间层次
- 轻微圆角边框
- **比细描边更厚实一点的暖白轻实体边框**
- 边框有柔和高光与轻微层次，但不过宽、不过金、不过重
- 左文右机的清晰信息结构
- 毛玻璃信息卡 + 真实设备主视觉

## 最稳的使用方法

新开一个 GPT 对话，同时上传：

1. `SKILL.md`
2. `REFERENCE_CANONICAL_16x9.jpg`

然后说：

> 按附件 Skill 和参考图，给我做一个关于「XXX」的下周七 B站封面。风格保持一致，但根据本期内容重新设计版式，并兼顾 B站 4:3 中央裁切。

## 核心区别

这套 Skill 是 **B站横版封面**：16:9、暖奶杏自然光、真实产品摄影感、轻微圆角、比细描边更厚实一点的暖白轻实体边框。

不要与 TikTok / 抖音 3:4 的“黑色外缝 + 奶油香槟金实体框”混用。
